Автоматизация заявок на ремонт бытовой техники

О проекте

Проект автоматизирует обработку заявок для сервиса по ремонту бытовой техники с использованием n8n.

Рабочий процесс охватывает путь заявки от получения обращения клиента до завершения ремонта, включая подбор сотрудника, уведомления и обновление статусов.

Возможности

- Приём заявок через Webhook.
- Обработка и структурирование данных с помощью AI.
- Поиск клиента и создание заявки.
- Подбор свободного сотрудника по специализации.
- Уведомления сотрудников через Telegram.
- Управление статусами заявки с помощью Telegram-кнопок.
- Обработка ошибок и отсутствие свободного сотрудника.
- Сохранение истории взаимодействий.

Используемые технологии

- n8n
- Docker Desktop
- Telegram Bot API
- Webhook
- AI
- Таблицы данных
- Tailscale Funnel

Структура проекта

- `workflows/` — экспорт рабочего процесса n8n.
- `docs/` — описание проекта и структура базы данных.
- `examples/` — примеры входящих заявок с демонстрационными данными.

Структура базы данных

Проект использует пять таблиц:

- `Clients` — клиенты.
- `Employees` — сотрудники и их специализации.
- `Requests` — заявки и их статусы.
- `Interactions` — история взаимодействий.
- `pending_actions` — ожидающие действия сотрудников.

Подробное описание полей находится в файле `docs/Database_Schema.md`.

Запуск

Для запуска проекта необходимы:

1. Установленный Docker Desktop.
2. Запущенный экземпляр n8n.
3. Настроенные Telegram Credentials.
4. Настроенные переменные окружения и Webhook.
5. Подготовленные таблицы данных.

После импорта workflow необходимо подключить собственные учётные данные и проверить настройки узлов перед запуском.

Безопасность

В репозитории не должны находиться реальные токены, API-ключи, пароли, персональные данные клиентов и служебные файлы экземпляра n8n.

Примеры заявок предназначены только для демонстрации.

Статус

Основной рабочий процесс реализован и протестирован. Репозиторий предназначен для демонстрации проекта автоматизации бизнес-процессов.
