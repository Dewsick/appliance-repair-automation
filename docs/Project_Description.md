# Автоматизация заявок на ремонт бытовой техники

## О проекте

Проект представляет собой систему автоматизации обработки заявок для сервиса по ремонту бытовой техники, разработанную с использованием n8n.

Система автоматизирует основные этапы работы с заявками: от получения обращения клиента до завершения ремонта.

## Основные возможности

- Приём заявок через веб-форму.
- Обработка и структурирование данных с помощью искусственного интеллекта.
- Проверка наличия клиента в базе данных.
- Создание и обновление заявок.
- Подбор свободного сотрудника по специализации.
- Отправка уведомлений сотрудникам через Telegram.
- Управление статусами заявок с помощью кнопок в Telegram.
- Обработка ошибок и отсутствие подходящего свободного сотрудника.
- Сохранение истории взаимодействий с клиентами.

## Используемые технологии

- **n8n** — автоматизация рабочих процессов.
- **Docker Desktop** — локальный запуск n8n.
- **Telegram Bot API** — уведомления и управление заявками.
- **Webhook** — получение данных из веб-формы.
- **AI** — обработка и структурирование информации из обращений.
- **Таблицы данных** — хранение информации о клиентах, сотрудниках, заявках и взаимодействиях.
- **Tailscale Funnel** — предоставление внешнего доступа к локальному сервису.

## Жизненный цикл заявки

1. Клиент отправляет заявку через веб-форму.
2. Система обрабатывает и проверяет полученные данные.
3. Находит существующего клиента или создаёт новую запись.
4. Создаёт заявку в базе данных.
5. Ищет свободного сотрудника подходящей специализации.
6. Отправляет сотруднику уведомление с доступными действиями.
7. Обновляет статус заявки при принятии, назначении визита, начале и завершении ремонта.
8. Сохраняет историю взаимодействий и обрабатывает ошибки.

## Структура данных

Проект использует следующие таблицы:

- `Clients` — информация о клиентах.
- `Employees` — информация о сотрудниках.
- `Requests` — заявки, статусы и назначенные сотрудники.
- `Interactions` — история сообщений и взаимодействий.
- `pending_actions` — временное хранение ожидающих действий сотрудников.

## Безопасность

В публичной версии проекта используются демонстрационные данные. Пароли, API-ключи, токены Telegram и другие секретные данные не должны включаться в репозиторий.

Для запуска необходимо настроить собственные учётные данные и параметры подключения.

## Статус проекта

Основной рабочий процесс реализован и протестирован. Проект демонстрирует применение n8n для автоматизации обработки заявок, взаимодействия с сотрудниками и управления жизненным циклом ремонта.
